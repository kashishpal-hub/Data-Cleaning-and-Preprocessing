# Data Cleaning and Preprocessing – Internship Task 3

This project was completed as part of my Data Analytics Internship at Oasis Infobyte.

## Project Overview

Performed data cleaning and exploratory analysis on a dataset using Python to improve data quality and extract useful insights.

## Key Tasks Performed

* Explored the dataset
* Identified missing values
* Handled missing and duplicate data
* Checked and corrected data types
* Identified and handled outliers
* Cleaned inconsistent data
* Performed data preprocessing
* Analyzed cleaned data
* Created visualizations
* Extracted useful insights

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

This task helped me gain practical experience in exploring datasets, handling data quality issues, identifying outliers, and extracting useful insights through Python-based analysis and visualization.
